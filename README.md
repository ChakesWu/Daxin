# 答信 (Daxin)

**银行智能客服回答的第三方验收与分级放行。** 以经确认的制度版本为唯一标准，检查智能客服的回答，并回答一个决策问题：*这个主题能不能放给 AI 自动回答，依据是什么。*

> 状态：v0.1 开发预览。所有演示数据均为**仿真**（虚构机构代号 BANK-X），不代表任何真实机构或系统，也不是任何实测结果。
> 本工具是制度一致性检查与风险提示工具，不构成法律意见，不替代法务、合规与消保部门的判断。

## 它做什么

1. **制度内核**：条款拆成带产品、渠道、地区、语言、版本与生效区间的事实；经确认后**冻结**，冻结后只能新增版本，不能修改。
2. **观察**：被测智能体的回答以**只追加**方式入库（数据库触发器强制），回答先脱敏再存，另存原文哈希。
3. **判定**：按固定顺序判为通过、C1 与现行制度矛盾、C2 引用旧版、C3 混用其他范围的规则、C4 越权承诺、C5 需合规复核；抽不到主张时是“待人工”，**绝不判通过**。
4. **放行矩阵**：按主题×地区×渠道×语言给出 L1 全自动 … L4 必须人工；只计**人工复核**过的判定；比率附 Wilson 下界；样本不足、有未关闭的高危发现、标准有了新版本而未复测、结果过期，都只会**降级**。
5. **放行之后**
   - **路由策略**：`daxin route-export` 把放行矩阵导出为 JSON（`daxin.routing/1`），供智能客服的意图路由读取：L4 转人工、L2 AI 起草人工确认。未列出的范围默认 L4，过期按 L3，文件带 SHA-256，被改动即拒用；`daxin route-check` 是参考查询实现。答信不进入回答生成。
   - **生效前回归**：`daxin regress` 列出待生效的冻结条款须复测的问题和截止日，并按新标准预演已记录的回答（机器预演，不存储、不计入统计）。
   - **客户端出处**（`daxin/cite.py`）：只有与现行版本一致的主张附出处（文件、版本、生效日）；错的不附出处并转人工；抽不到主张的不附出处。
   - **测评报告范本**：`daxin report` 用工作区实际数据生成报告；尚未逐条对齐监管正式文本，须对齐处标【待对齐】。
6. **证据与审计**：每个确认的差异一张证据卡（链式校验）；整个工作区有哈希链审计日志（可选 HMAC）。
7. **匿名**：核心只见机构代号。对外导出时检查是否含 `private/institution_map.csv` 里的名称，含则拒绝。

## 快速开始

```bash
pip install -e ".[dev]"
daxin demo --dir .daxin-demo        # 端到端演示（仿真）
python -m pytest -q                 # 109 项测试
daxin export-demo --out site/index.html   # 导出可离线打开的演示网页（外部客户视角 + 内部验收视角）
```

演示会依次展示：冻结的条款无法被改动；对 200 余条仿真回答判定；放行矩阵；一次标准变更使放行降级并触发生效前回归；复测后恢复；放行矩阵导出为路由策略；证据卡与审计链校验。

## 用于真实的人工测试

`testkit/` 是一套**纯人工、离线**的测试套件（标准答案登记表、115 题题库、观察记录表、分析程序、询问信与试点提案模板），**不含任何访问外部系统的程序**。使用前请读 `testkit/README.md` 的行为规则。

```bash
daxin init --ws .daxin
daxin policy import-register testkit/ground_truth_register.xlsx --freeze --by 甲   # 标准答案
daxin observe-import testkit/test_log.xlsx testkit/question_bank.xlsx             # 观察与人工判定
daxin judge && daxin release --by topic,region,channel,language
daxin evidence out/evidence_cards.md --public      # 对外导出：需要 private/institution_map.csv
```

## 限制（如实）

- 抽取只覆盖有限句式：阿拉伯数字、中文数字（到 999）、英文与葡文数字词（到 999）、常见单位、百分比；复杂条件、多重否定、表格式回答可能漏判，漏判落入“待人工”。语言包（`daxin/lang.py`）：简体、繁体、英文、葡文，按回答声明的语言选用；只有单元测试，尚未用真实回答检验准确率。
- R1–R4 分级、L1–L4 门槛、过期天数均为**示例阈值**，需用试点数据与银行意见校准；影响面是代理指标，不是真实流量。
- 一个工作区对应一个机构代号。
- 尚无任何真实机构的数据；演示中的数字来自仿真。
- 观察层目前只支持记录表导入；HTTP 适配器（仅授权测试环境）、REST 尚未实现。演示网页是由仿真运行导出的静态页面，不是可操作的管理界面。
- 路由策略与客户端出处只提供格式与参考实现，尚未接入任何真实智能客服；报告范本尚未对齐监管正式文本。
