# LLM 数字标注：对靶场第一轮 102 条回答的一次真实运行（仿真）

`daxin judge --llm` 让模型标注回答里每个数字属于哪个事实；程式核对引文、取值后才采信。这里是 `glm-5.3-flashx`（effort=low）对靶场第一轮回答的一次运行，原始输出在 `raw/`，可离线重放：

```
daxin judge --ws <靶场工作区> --llm --raw-dir testkit/claims_eval/raw --replay
```

前提：标准里要有被标注的“另一个事实”。本次在工作区里补冻结了一条 `withdrawal.min_fee`（取现手续费最低 10 元）；没有这条标准，数字 10 就无从核对，仍会待人工。

| 轮 | 纯规则 rules-0.4 | 规则加 LLM 标注 |
|---|---|---|
| A1 | 通过 32，待人工 2 | 通过 34 |
| B2 | 通过 30，待人工 3，C3 1 | 通过 32，待人工 1，C3 1 |
| C3 | 通过 24，待人工 7，C3 1，C2 2 | 通过 25，待人工 6，C3 1，C2 2 |

只有 5 条判定改变，全部是“取现限额与手续费同句出现”由待人工转为通过，我逐条看过文字，都是正确回答。没有任何错误回答因此被放过。

限制：只有 102 条、1 次运行、同一个模型；机器判定仍是建议，不是准确率；模型把错误数字当作无关数字的风险只被“取值须等于另一个冻结事实的值”这一条核对挡住，不能说完全消除。
