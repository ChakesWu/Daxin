# 离线评测试点提案（单一场景）

| 项目 | 内容 |
|---|---|
| 场景 | 【例如：某一类信用卡的客服问答】 |
| 周期 | 4 周 |
| 数据 | 合成测试集 + 贵行提供的制度文件；不接触客户数据；数据不出行 |
| 我方做 | 将制度结构化（经贵行确认后冻结）；生成测试集；在测试环境评测；输出验收报告、证据卡、放行建议 |
| 贵行做 | 提供制度文件与测试环境入口；指定业务、合规或消保联系人，确认条款与判定 |
| 交付物 | 制度基准库、测试集、验收报告、制度冲突清单、证据包 |
| 成功标准（建议） | 条款结构化覆盖率；经贵行确认的有效发现数；误报率；复测通过率 |
| 数据与保密 | 评测在行内环境运行；结果归贵行；我方不留存；可签保密协议 |
| 不做 | 不出具法律意见；不替代法务、合规、消保的判断；不对外披露 |
